# КХЛ Плей-офф 2026 — Сайт прогнозов

Спортивный сайт для прогнозов на плей-офф КХЛ с таблицей лидеров.

## Технологии

- **Frontend**: Чистый HTML/CSS/JS — без сборщиков, сразу работает
- **Backend**: [Firebase](https://firebase.google.com) (бесплатный Spark план)
  - Authentication (Email/Password)
  - Firestore (база данных)
- **Хостинг**: GitHub Pages (бесплатно)

---

## Быстрый старт

### 1. Создай Firebase проект

1. Зайди на [console.firebase.google.com](https://console.firebase.google.com)
2. Нажми **Add project** → придумай название → создай
3. В левом меню: **Authentication** → **Get started** → включи **Email/Password**
4. В левом меню: **Firestore Database** → **Create database** → выбери регион → **Start in test mode** (потом добавишь правила)
5. В левом меню: ⚙ **Project settings** → вкладка **General** → раздел **Your apps** → нажми **</>** (Web) → зарегистрируй приложение
6. Скопируй `firebaseConfig`

### 2. Вставь конфиг в `js/config.js`

```javascript
const FIREBASE_CONFIG = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

### 3. Настрой правила безопасности Firestore

В консоли Firebase: **Firestore** → **Rules** → вставь содержимое файла `firestore.rules` → **Publish**

### 4. Обнови команды плей-офф (когда станут известны пары)

В файле `js/config.js` найди раздел `BRACKET` и обнови команды:

```javascript
west: {
  r1: [
    { id: "w1", home: "ЦСКА",     away: "Витязь"     },
    { id: "w2", home: "СКА",      away: "Динамо Рига" },
    // ... и т.д.
  ]
},
east: {
  r1: [
    { id: "e1", home: "Металлург Мг", away: "Трактор" },
    // ...
  ]
}
```

- `home` — команда с преимуществом своего льда (более высокий посев)
- `away` — гостевая команда

### 5. Задеплой на GitHub Pages

```bash
git add .
git commit -m "initial setup"
git push origin main
```

Затем в настройках репозитория: **Settings** → **Pages** → **Source: Deploy from a branch** → выбери `gh-pages` ветку.

Сайт будет доступен по адресу: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

## Как сделать себя администратором

1. Зарегистрируйся на сайте
2. В Firebase консоли: **Firestore** → коллекция `users` → найди свой документ → поставь `isAdmin: true`
3. После этого у тебя появится пункт **⚙ Админ** в навигации

---

## Как вводить результаты

1. Открой `/admin.html`
2. Для каждой завершённой серии:
   - Выбери победителя из выпадающего списка
   - Выбери количество игр (4/5/6/7)
   - Поставь галочку **"Серия завершена"**
3. Нажми **Сохранить всё**

Очки в таблице лидеров пересчитаются автоматически.

---

## Система очков

| Раунд          | Очков за победителя | Бонус за кол-во игр |
|----------------|--------------------:|--------------------:|
| 1/8 финала     | 1                   | +1                  |
| 1/4 финала     | 2                   | +1                  |
| 1/2 финала     | 4                   | +1                  |
| Финал КГ       | 8                   | +1                  |

Максимальное количество очков: **15 серий × (макс. 9 за финал) = ~105 очков**
